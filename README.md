# JAVASCRIPT-PROJECTS
This Repository contains the projects and assignments I completed as part of my JavaScript course through The Tech Academy's UX/UI design Bootcamp.

Throughout this course, I developed foundational skills in JavaScript programming, DOM manipulation, event handling, conditional logic, functions, and interactive web development. These projects demonstrate my progression from basic programming concepts to building dynamic and responsive user experiences.

PROJECTS

Tic Tac Toe
An interactive Tic Tac Toe game built using JavaScript, HTML, and CSS.
This project demonstrates the use of JavaScript to manage game logic, respond to player interactions, track turns, and determine winning conditions.

Pizza Project
An interactive pizza-ordering application that allows users to customize their pizza by selecting different sizes and toppings.
JavaScript is used to process the selected options, calculate the total price, and display an itemized order.

Calculator
A functional calculator developed using HTML, CSS, and JavaScript. 
This project demonstrates how JavaScript can be used to process numerical input, perform arithmetic operations, and update the display dynamically.

AJAX Project
A newsletter sign-up interface demonstrating asynchronous communication between a browser and a local server.
Using the XMLHttpRequest object, the application retrieves HTML content and displays a personalized confirmation message without requiring a full-page refresh.

jQuery Project
An interactive Class Cars webpage featuring animated visual effects and interactive content.
The project uses jQuery to create an animated shine effect, resize a heading based on scroll position, reveal car titles on hover, and expand or collapse FAQ answers.

Additional Exercises
Throughout the course, I also completed smaller programming exercises exploring fundamental JavaScript concepts including:
expressions and variables, functions, mathematical operators, dictionaries and objects, comparisons and type coercion, conditional statements, loops and arrays.

These exercises helped establish the programming fundamentals used throughout the larger projects.

What I Learned
This course strengthened my understanding of how JavaScript adds functionality and interactivity to websites.
By working with user input, dynamic content, animations, and browser events, I gained practical experience connecting visual design with functional code. 
As I continue developing my skills in UX/UI design, understanding front-end development helps me approach interface design with a stronger awareness of usability, technical implementation, and the relationship between design and functionality.
